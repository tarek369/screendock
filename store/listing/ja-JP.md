# ScreenDock: ja-JP

## Title
ScreenDock: AirPlayレシーバー

## Short description
広告なし・買い切りのAirPlayレシーバー。Mac・iPhone・iPadの画面をAndroidに映せます

## Full description
ScreenDockは、Androidのスマートフォン、タブレット、テレビをAirPlayレシーバーに変えるアプリです。Mac、iPhone、iPadの画面をWi-Fi経由でミラーリングし、Appleデバイスから音楽をストリーミングしたり、対応アプリの動画を送ったりできます。

画面ミラーリング
MacやiPhone、iPadの画面をAndroidデバイスに映します。H.264とH.265（HEVC）の映像を最大4K・60 fps、ディスプレイのネイティブ解像度で表示します。音声はAACまたはApple Lossless（ALAC）です。

AndroidタブレットやモニターをMacのセカンドディスプレイとして使えます。ケーブルもアダプターも不要です。iPhoneやiPadの画面を、使っていないAndroid端末に映してポータブル画面にすることもできます。

AirPlayオーディオ
iPhone、iPad、Macから音楽をストリーミングできます。ロスレスのALACにも対応しています。再生中の曲名、アーティスト名、ジャケット画像が画面に表示されます。

AirPlayビデオ
YouTubeやWebの動画を、AirPlayボタンからApple端末のScreenDockへ送れます。再生はAndroid端末で行われます。

Android TV・Google TV
Android TVやGoogle TVにインストールすると、Appleデバイスのメニューに AirPlayレシーバーとして表示されます。

主な機能
- macOS、iOS、iPadOSからの画面ミラーリング
- 再生中の情報とジャケット画像に対応したAirPlayオーディオレシーバー
- 対応アプリやWebサイトからのAirPlayビデオ
- Android TVとGoogle TVに対応
- 映像をフィット、フィル、ズームで調整
- 任意のPIN設定と、新しい送信元ごとの「許可前に確認」
- 端末の起動時に自動で開始
- ステータス通知からレシーバーを停止
- オープンソース（UxPlayコアを使用）

無料版とPro版
無料版ではセッションが10分に制限されます。ScreenDock Proは買い切りの1回限りの購入で、サブスクリプションも広告もありません。

動作条件
- 送信側と受信側を同じWi-Fiネットワークに接続（遅延を抑えるには5 GHz推奨）
- 画面ミラーリングまたはAirPlayに対応したAppleデバイス

ご注意
- DRMで保護されたコンテンツ（Netflix、Disney+、Apple TV+など）はミラーリングできません。これは保護技術による技術的な制限であり、不具合ではありません。
- ScreenDockは独立したオープンソースプロジェクト（GPLv3）で、Apple Inc.とは提携していません。「AirPlay」はApple Inc.の商標です。
